VERSION 40 MINUTES - RÉPONSE NON OBLIGATOIRE

Modifications :
- Durée du test : 40 minutes.
- Suppression du bouton Passer.
- La réponse n’est pas obligatoire.
- Ajout de l’option "Je ne sais pas" à chaque question.
- "Je ne sais pas" est compté comme réponse incorrecte.
- Les 20 questions sont posées dans un ordre aléatoire.
- Le micro reste obligatoire.
- Le rapport automatique indique le nombre de réponses "Je ne sais pas".

- config.js
- CODE_GOOGLE_APPS_SCRIPT.gs

VERSION SANS REPONSE OBLIGATOIRE ET SANS PRECEDENT

Modifications :
- Les réponses ne sont plus obligatoires.
- Le candidat peut cliquer sur "Suivant" sans répondre.
- Les questions sans réponse sont signalées dans le rapport.
- L’option "Je ne sais pas" reste disponible, mais elle n’est pas obligatoire.
- Le bouton "Précédent" a été supprimé.
- Le candidat ne peut donc pas revenir en arrière.
- Durée conservée : 40 minutes.
- Micro obligatoire conservé.
- Envoi automatique par e-mail conservé.
